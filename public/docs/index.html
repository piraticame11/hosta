How to Host Your Site on Hosta

Step-by-step instructions for deploying modern websites, configuring custom DNS, provisioning MySQL and PostgreSQL databases, and automating infrastructure via our developer API.

01

Quick Start: Deploying Your First Web Domain

Launch a live web domain in under 60 seconds with automated Let's Encrypt SSL.

STEP 1

Provision Domain

Open the Student Portal → Web Domain tab, enter your desired domain name (e.g. mysite.hosta.site), and click Create Domain.

STEP 2

Upload Web Files

Connect via SFTP or Web File Manager. Put your HTML/CSS/JS or Node.js assets into the generated public_html directory.

STEP 3

Auto-SSL Activated

Let's Encrypt certificates are automatically requested and bound to Nginx. Your website is immediately accessible via secure https://.

Automated Linux Directory Structure

When a domain is added to Hosta via the dashboard or API, our HestiaCP automation provisions an isolated root directory structure under your system user profile:

# Production Directory Layout
/home/{username}/web/{your-domain.com}/
├── public_html/           # Web root served to visitors
├── index.html           # Default landing or SPA entrance
├── assets/               # CSS, Javascript bundles, images
└── server.js             # Optional Node.js Express backend entry
├── logs/                  # Access and error logs (Nginx + Apache)
└── stats/                 # AWStats & visitor analytics

02

Connecting Custom Domains & DNS Setup

Point your own domain from Namecheap, GoDaddy, or Cloudflare to your Hosta container.

Whether you are using a free *.hosta.site subdomain or pointing an apex domain like myproject.com, DNS records translate your domain into our server's IP address.

Required DNS Records for External Registrars TTL: Automatic / 300s
Type Host / Name Target / Value / IP Proxy / Status Purpose
A @ (root) 142.91.97.73 DNS Only / Proxied Points root apex domain to Hosta server
A www 142.91.97.73 DNS Only / Proxied Routes www.yourdomain.com requests
CNAME subdomain hosta.site CNAME Alias Optional alias mapping for subdomains

🛡️ Cloudflare Edge Proxy & SSL Handshake

When using our default free subdomains (*.hosta.site), traffic routes through Cloudflare's global edge network before reaching our server cluster on port 8083 / 443. This gives your student applications immediate DDoS protection, HTTP/3 protocol support, and automatic wildcard SSL.

Verifying DNS Propagation (Terminal Commands)

Run these commands in your local command prompt or terminal to confirm your DNS records have fully propagated: 

dig +short A yourdomain.com @1.1.1.1
nslookup yourdomain.com 8.8.8.8
⚠️

Note on DNS Propagation: External domain updates at registrars like GoDaddy or Namecheap can take anywhere from 5 minutes to 24 hours to spread worldwide. Do not request Let's Encrypt certificates until the A record resolves to our IP address.

How to Import Your School SQL Dump (.sql file)

  1. Log in to your Student Portal and navigate to the Databases tab.
  2. Click New Database, choose a name (e.g. hostb_capstone), and note the generated password.
  3. Click the Open phpMyAdmin link in your dashboard.
  4. Log in using your full database username (e.g. hostb_capstone) and password.
  5. Select your database on the left sidebar, click the Import tab on top, choose your .sql file, and click Go.
04

Developer REST API Reference

Automate domain provisioning, databases, and quota monitoring via programmatic HTTPS requests.

Base Endpoint: https://hosta.site/api/hosting JSON Payload & Responses
Method Endpoint Path Description Auth Required
POST /api/hosting/domains Provisions a new web domain + triggers Let's Encrypt SSL Bearer Token
GET /api/hosting/domains Lists all active web domains for user Bearer Token
POST /api/hosting/databases Creates a new MySQL database + database user Bearer Token
GET /api/hosting/databases Fetches database list and connection credentials Bearer Token
GET /api/hosting/stats Returns disk, bandwidth, database, and email metrics Bearer Token
Example: Create a New Web Domain 
curl -X POST https://hosta.site/api/hosting/domains \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_SESSION_TOKEN" \
  -d '{
    "domain": "myproject.hosta.site",
    "enableSsl": true
  }'
const axios = require('axios');

async function provisionDomain() {
  try {
    const response = await axios.post('https://hosta.site/api/hosting/domains', {
      domain: 'myproject.hosta.site',
      enableSsl: true
    }, {
      headers: {
        'Authorization': 'Bearer YOUR_SESSION_TOKEN',
        'Content-Type': 'application/json'
      }
    });

    console.log('Domain Provisioned:', response.data);
  } catch (error) {
    console.error('Error:', error.response?.data || error.message);
  }
}

provisionDomain();
const response = await fetch('https://hosta.site/api/hosting/domains', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer YOUR_SESSION_TOKEN'
  },
  body: JSON.stringify({
    domain: 'myproject.hosta.site',
    enableSsl: true
  })
});

const result = await response.json();
console.log(result);
import requests

url = "https://hosta.site/api/hosting/domains"
headers = {
    "Authorization": "Bearer YOUR_SESSION_TOKEN",
    "Content-Type": "application/json"
}
payload = {
    "domain": "myproject.hosta.site",
    "enableSsl": True
}

response = requests.post(url, json=payload, headers=headers)
print(response.json())
