HestiaCP Quick Setup Guide

1
Generate API Key in HestiaCP

Log in to your HestiaCP Web Interface as admin, navigate to Server Settings > Users > API Access Keys, and click Add Access Key.

Or CLI: v-add-access-key admin hosta-api
2
Open Port 8083 in Firewall

Verify that incoming traffic on TCP port 8083 is allowed in your server's firewall.

ufw allow 8083/tcp
3
Connect & Test

Input your server details, click Test Server Connection to verify, then save settings.
